# Detektyw narracji — NPF

Wersja 4.0. Indywidualne przygotowanie do C5: wybierz program swojego zespołu (SCT, BO, GPA, BK2%, Czyste Powietrze), zbadaj narrację A, zapisz interpretację, odkryj B i przygotuj końcowy raport.

[Uruchom grę](https://rszarf-1.github.io/detektyw-narracji-npf/)

Sześć pytań z wyjaśnieniami i dwa otwarte raporty. Orientacyjnie 15–20 minut; czas wymaga pilotażu. Narracje są fikcyjne, programy rzeczywiste. Słownik zawiera przykłady dla wybranego programu. Postępy zapisują się lokalnie; dostępne są eksport i import JSON oraz raport TXT.

Przed C5, do poniedziałku 15:00, student oddaje własny kod NPF2 przez formularz UW podlinkowany w grze. Kod obejmuje pierwsze i końcowe wybory oraz oba raporty. Automat ocenia tylko pytania zamknięte. Kod nie dowodzi samodzielności. Formularz zbiera zweryfikowany e-mail UW.

Na C5 studenci porównują indywidualne interpretacje i analizują autentyczne źródło o swoim programie. Nie przechodzą drugiej pełnej gry zespołowej.

Jeden plik HTML, działa offline. Formularz i zewnętrzne źródła wymagają internetu. Lokalny dekoder i dane studentów nie są publikowane w repozytorium.

Na podstawie Jones i in. (2023), rozdział Narrative Policy Framework. Materiał przygotowany z pomocą AI.
